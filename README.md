# Live Translator Overlay

Десктопное приложение для Windows 10/11, которое слушает звук на компьютере (системный звук или микрофон), распознаёт речь локально через **faster-whisper**, автоматически определяет язык каждой реплики и показывает перевод в маленьком плавающем окне поверх всех приложений.

## Возможности

- Источник звука: **системный звук** (Zoom, YouTube, игры, звонки) или **микрофон**; можно выбрать конкретное устройство.
- Локальное распознавание faster-whisper: модели `tiny`, `base`, `small` (по умолчанию), `medium`, `large-v3-turbo`.
- Автоопределение языка **для каждой реплики отдельно**; при низкой уверенности — «Язык не определён», перевод всё равно выполняется.
- Перевод:
  - **локально** через Argos Translate (без интернета после однократной загрузки языковых пакетов);
  - через **DeepL API** или **OpenAI API** (а также любой OpenAI-совместимый сервер: LM Studio, Ollama, vLLM).
  - Кэш повторяющихся фраз (в памяти и на диске).
- Окно: frameless, всегда поверх, перетаскивается, меняет размер за любой край, прозрачность 10–100 %, компактная полоска, история реплик с прокруткой.
- Одновременно видны: оригинал, определённый язык и перевод.
- Индикатор состояния: слушает / загрузка / остановлено / ошибка микрофона / ошибка перевода, плюс индикатор уровня сигнала.
- Глобальная горячая клавиша **Ctrl+Alt+T** — старт/стоп из любой программы.
- Кнопка «Скрыть окно» — остаётся иконка в трее; щелчок по ней возвращает окно.
- Настройки сохраняются в `%APPDATA%\LiveTranslatorOverlay\settings.json`.

## Структура проекта

```
live_translator_overlay/
├── main.py             запуск приложения, логирование, перехват исключений
├── audio_capture.py    захват микрофона (sounddevice) и системного звука (PyAudioWPatch, WASAPI loopback)
├── transcriber.py      QThread: нарезка потока на реплики + faster-whisper
├── translator.py       QThread перевода: Argos / DeepL / OpenAI + кэш
├── overlay_window.py   плавающее окно, компактный режим, трей, диалог настроек
├── hotkey.py           глобальная горячая клавиша Windows (RegisterHotKey)
├── settings.py         настройки в JSON, списки языков
├── requirements.txt
└── README.md
```

Конвейер: `аудио-callback → очередь блоков 100 мс (16 кГц моно) → сегментация по паузам (2–5 с) → Whisper (язык + текст) → сигнал в GUI → поток перевода → сигнал в GUI`. Захват и распознавание идут в отдельном `QThread`, перевод — в другом, поэтому интерфейс не зависает, а медленный перевод не задерживает распознавание.

## Почему PyAudioWPatch для системного звука

- Готовые wheel-пакеты под Windows для Python 3.8–3.13 — ничего не нужно компилировать.
- Даёт отдельное loopback-устройство для каждого выхода (динамики, наушники, HDMI) и функцию `get_default_wasapi_loopback()`.
- Работает через callback PortAudio, как и sounddevice: низкая задержка, нет активного ожидания.
- Не требует включать «Стерео микшер» в Windows.
- Альтернатива `soundcard` работает, но известна предупреждениями `data discontinuity` и проблемами совместимости с новыми версиями NumPy.

## Установка

Требуется **Python 3.10–3.12** (64-bit). На 3.13 тоже работает, но у части зависимостей Argos (torch/stanza) колёса для новых версий Python выходят с задержкой.

### 1. Создание виртуального окружения

PowerShell:

```powershell
cd путь\к\live_translator_overlay
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Если PowerShell запрещает запуск скриптов:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

cmd.exe:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
```

### 2. Установка зависимостей

```powershell
pip install -r requirements.txt
```

`argostranslate` подтягивает `torch` (CPU-версия, ~200 МБ) через `stanza` — это нормально.

### 3. (Необязательно) Ускорение на NVIDIA GPU

faster-whisper (CTranslate2 4.x) использует CUDA 12 + cuDNN 9. Самый простой способ — поставить библиотеки из pip, программа сама подключит их DLL:

```powershell
pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
```

В настройках выберите «Вычисления: Авто» или «GPU (CUDA)». Если GPU недоступен, программа автоматически переключится на CPU.

### 4. Запуск

```powershell
python main.py
```

Без консольного окна:

```powershell
pythonw main.py
```

При первом старте прослушивания скачивается модель Whisper (`small` ≈ 480 МБ) в `%APPDATA%\LiveTranslatorOverlay\models`, а при первой встрече пары языков — пакет Argos (≈ 50–100 МБ). После этого интернет не нужен. Пакеты можно скачать заранее: **Настройки → Перевод → Скачать офлайн-пакеты**.

## Как выбрать системный звук как источник в Windows

1. Откройте ⚙ **Настройки → Звук и распознавание**.
2. **Источник звука:** «Системный звук».
3. **Устройство:**
   - «Динамики по умолчанию (Windows)» — захватывается то устройство, через которое Windows сейчас воспроизводит звук;
   - или конкретное устройство с пометкой `[Loopback]`, например `Наушники (Realtek(R) Audio) [Loopback]`.
4. Проверьте, что звук из нужной программы идёт именно через это устройство: **Параметры Windows → Система → Звук → Вывод**, а для отдельных программ — **Параметры → Система → Звук → Микшер громкости** (Windows 11) / **Параметры устройств и громкости приложений** (Windows 10).
5. В Zoom/Teams/Discord проверьте, какое устройство выбрано как «Динамик» в настройках самой программы.
6. Нажмите «Сохранить» и «▶ Старт». Если звук идёт, индикатор уровня в заголовке окна будет двигаться.

Включать «Стерео микшер» не нужно. Если вы сменили устройство вывода (подключили наушники) во время работы — нажмите «Стоп» и «Старт».

## Решение частых проблем

### Аудио

| Симптом | Решение |
|---|---|
| «Ошибка системного звука: PyAudioWPatch не установлен» | `pip install PyAudioWPatch` (только Windows). |
| «Не найдено loopback-устройство» | Проверьте, что в Windows есть активное устройство вывода. Обновите драйвер звука. Выберите устройство вручную в настройках. |
| Индикатор уровня не двигается | Звук идёт через другое устройство. Выберите его явно в настройках (кнопка ⟳ обновляет список). При тишине loopback не присылает данные — это нормально. |
| Bluetooth-гарнитура: звук пропадает или становится «телефонным» при старте | Гарнитура переключается в режим Hands-Free, когда используется её микрофон. Для системного звука выберите устройство `… Stereo [Loopback]`, а не `… Hands-Free`. |
| «Ошибка микрофона: … Invalid sample rate / Invalid device» | Выберите другой микрофон в настройках; закройте программы, захватившие микрофон в монопольном режиме (Панель управления → Звук → Запись → Свойства → Дополнительно → снимите «Разрешить приложениям использовать устройство в монопольном режиме»). |
| Микрофон «молчит» | **Параметры → Конфиденциальность и защита → Микрофон**: включите «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону». |
| `OSError: PortAudio library not found` | `pip install --force-reinstall sounddevice` (колесо для Windows уже содержит PortAudio). |

### CUDA / CPU

| Симптом | Решение |
|---|---|
| `Library cublas64_12.dll is not found` или `cudnn_ops64_9.dll` | `pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"`. Программа и так автоматически переключится на CPU, а в статусе будет написано `CPU int8`. |
| `CUDA driver version is insufficient` | Обновите драйвер NVIDIA (нужна поддержка CUDA 12). |
| GPU старый (GTX 9xx/10xx) и ошибка `float16` | Программа сама попробует `int8_float16`, затем CPU. |
| Высокая загрузка CPU / большая задержка | Модель `base` или `tiny`, beam size = 1, фрагмент 2–3 с. |
| `OMP: Error #15: Initializing libiomp5md.dll` | Уже обрабатывается в `main.py` (`KMP_DUPLICATE_LIB_OK=TRUE`). Если запускаете модули отдельно — задайте эту переменную окружения. |
| Ошибка загрузки модели `403`/`timed out` | Нет доступа к huggingface.co. Проверьте интернет/прокси; можно один раз скачать модель на другом ПК и скопировать в `%APPDATA%\LiveTranslatorOverlay\models`. |

### Перевод

| Симптом | Решение |
|---|---|
| «Ошибка перевода: Нет интернета…» | Для локального режима пакет пары языков нужно один раз скачать. Подключитесь к интернету или нажмите «Скачать офлайн-пакеты». |
| «Argos не поддерживает пару …» | Переключитесь на DeepL/OpenAI для этой пары. |
| «DeepL: неверный API-ключ» | Ключи бесплатного тарифа заканчиваются на `:fx` — программа сама выбирает правильный адрес API. |
| «OpenAI: превышен лимит» | Проверьте баланс аккаунта. Включённая опция «При ошибке API переводить офлайн» переключит перевод на Argos. |

Журнал работы: `%APPDATA%\LiveTranslatorOverlay\app.log`.

## Приватность

- Звук **всегда** обрабатывается только на вашем компьютере, в облако аудио не отправляется ни в одном режиме.
- В локальном режиме (Argos) в интернет не уходит ничего, кроме однократной загрузки моделей.
- В режимах DeepL/OpenAI отправляется только распознанный **текст** реплики.
- API-ключи хранятся в `settings.json` в вашем профиле в открытом виде — не передавайте этот файл другим.

## Как сделать распознавание точнее и с меньшей задержкой

**Меньше задержка**

1. GPU + CUDA — самый большой выигрыш (в 5–20 раз быстрее CPU).
2. Модель `base` или `small` на CPU; `medium`/`large-v3-turbo` — только с GPU.
3. «Макс. длина фрагмента» 2–3 с: реплики появляются быстрее (но короткие фрагменты хуже по контексту).
4. Beam size = 1 (жадное декодирование) — заметно быстрее при небольшой потере точности.
5. Если вы знаете язык речи — укажите его вместо автоопределения: пропускается шаг определения языка и исключаются ошибочные переключения языка.
6. Перевод через Argos на CPU быстрый; DeepL добавляет сетевую задержку ~100–300 мс, LLM-перевод — 0.5–2 с.

**Выше точность**

1. Модель побольше: `small` → `medium` → `large-v3-turbo` (на GPU `large-v3-turbo` почти так же быстра, как `medium`, и точнее).
2. Фрагмент 4–5 с и beam size 3–5: больше контекста — меньше ошибок.
3. Для микрофона: гарнитура или направленный микрофон, отключите в Windows «улучшения звука», говорите на расстоянии 10–20 см.
4. Для системного звука: громкость источника не на минимуме; уровень в окне должен заметно двигаться при речи. Фоновая музыка снижает качество.
5. Оставьте включённым фильтр тишины (Silero VAD) — он убирает «галлюцинации» Whisper на тишине и музыке.
6. Если собеседник говорит на одном языке — зафиксируйте «Язык речи»: короткие реплики (1–2 слова) автоопределение распознаёт ненадёжно.
7. Для лучшего качества перевода используйте DeepL или OpenAI: они лучше справляются с разговорной речью и обрывками фраз, чем офлайн-модели Argos.
